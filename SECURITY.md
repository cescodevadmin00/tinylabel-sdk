# Security / Seguridad

This SDK operates a local Bluetooth device. It does not provide a network server, authentication layer, or sandbox for untrusted images. Keep Pillow and transport dependencies updated within compatible versions, restrict filesystem access, and validate inputs in the host application. Job journals can contain printer identifiers and business label IDs; protect them as application data.

For a sensitive vulnerability, use the repository's private **Report a vulnerability** option when available. If it is unavailable, open an issue requesting a private reporting channel without publishing exploit details, secrets or customer information. No response-time SLA is offered for this experimental project.

Este SDK controla un dispositivo Bluetooth local. No proporciona servidor de red, autenticación ni aislamiento para imágenes no confiables. Actualiza dependencias compatibles, restringe acceso a archivos y valida entradas en la aplicación. Los registros pueden contener identificadores de impresora y etiquetas; protégelos.

Para vulnerabilidades sensibles usa **Report a vulnerability** si está disponible. Si no, solicita en una incidencia un canal privado sin publicar detalles de explotación, secretos ni datos de clientes. No se ofrece SLA de respuesta en esta versión experimental.
